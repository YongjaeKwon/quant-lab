# 포트폴리오 설명용 메모

`quant-lab`은 개인 프로젝트(quant-core)의 공개용 쇼케이스입니다.

## 한 줄 설명

개인 프로젝트(quant-core)에서 공개 가능한 구조만 분리한 FastAPI 백엔드 학습 저장소입니다.

## 강조할 점

- FastAPI 라우터와 서비스 계층을 분리했습니다.
- 데모 인증 흐름을 만들고 보호된 API에 연결했습니다.
- 백테스트 실행 결과를 WebSocket 이벤트로 대시보드에 전달했습니다.
- Docker Compose로 실행 흐름을 정리했습니다.
- 실제 전략과 투자 데이터는 공개하지 않았습니다.

## 이력서·포트폴리오 문장

개인 프로젝트(quant-core)에서 FastAPI·Docker 기반 백엔드를 직접 구성했고, 공개용 저장소 `quant-lab`에는 인증, WebSocket 이벤트, 백테스트 API, 대시보드 연동 구조만 안전하게 분리해 정리했습니다.
