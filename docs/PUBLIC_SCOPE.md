# 공개 범위

이 저장소는 공개 가능한 기술 구조만 보여주기 위해 만들었습니다.

## 포함한 것

- FastAPI 앱 구조
- 라우터 분리
- 데모 인증 토큰
- 백테스트 요청·응답 모델
- WebSocket 이벤트 전달
- Docker Compose 실행 예시
- 정적 대시보드

## 제외한 것

- 실제 전략 파일
- 거래소·증권사 연동 코드
- 주문, 포지션, 계좌 처리 코드
- 실제 시장 데이터
- 실험 결과, 수익률, 리서치 로그
- 비밀번호, API 키, 토큰
- 운영 자동화 스크립트

## 공개 원칙

1. 구조 설명에 필요한 코드만 남깁니다.
2. 성과를 오해하게 만드는 수치는 넣지 않습니다.
3. 보안 값은 `.env.example`에 예시 이름만 둡니다.
4. 실제 운용 가능한 자동매매 코드는 공개하지 않습니다.
