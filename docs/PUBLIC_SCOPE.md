# 공개 범위

## 이 저장소의 성격

ReachRich Public Lab은 비공개 개인 프로젝트 `ReachRich`의 일부 설계 결정을 설명하는 실행형 공개 companion이다. 운영 저장소를 비식별화해 복사한 것이 아니라, 공개 가능한 도메인 모델과 저장 경계를 합성 데이터로 다시 구현했다.

따라서 이 저장소에서 확인할 수 있는 것은 코드 구조와 처리 방식이다. 실제 투자 대상, 계좌 상태, 전략의 유효성이나 운용 성과를 확인할 수는 없다.

## 포함하는 것

- 고정 규칙으로 생성한 가상 계좌·보유 항목·OHLCV·환율
- 날짜 기준으로 다시 실행할 수 있는 시드 파이프라인
- SQLAlchemy·SQLite 계좌 스냅샷 저장
- pandas·Parquet 캔들 upsert
- 기준일별 가상 universe JSON
- 정렬·중복·미래 데이터·OHLC 일관성 검증
- FastAPI 읽기 API와 Pydantic 응답 모델
- React·TypeScript 대시보드
- 금액 가리기, 테마, 로딩·오류·빈 상태, 비활성 탭 폴링 중단
- pytest·Vitest·프로덕션 빌드를 실행하는 읽기 전용 CI

## 포함하지 않는 것

- 실제 계좌 번호, 보유 종목, 잔고와 손익
- 토스증권·KRX 또는 다른 외부 서비스의 요청·응답과 연동 코드
- client ID, secret, access token 등 자격증명
- 실제 종목 universe와 수집 데이터
- 구체적인 전략 로직, 파라미터, 신호와 주문 규칙
- 백테스트·모의투자·실거래 성과
- 주문·정정·취소·승인 기능
- 텔레그램 알림, 로컬 작업 스케줄과 GitHub Actions 운영 로그
- 비공개 저장소의 테스트 코드 전체와 내부 문서

`SAMPLE-A` 같은 이름과 화면에 표시되는 금액은 실제 값을 변형한 것이 아니라 처음부터 가상으로 만든 값이다.

## 비공개 프로젝트와의 대응 관계

| 비공개 ReachRich의 관심사 | 이 공개 저장소에서 보여주는 방식 | 제외한 경계 |
| --- | --- | --- |
| 계좌 상태를 날짜별로 기록 | 합성 `AccountSnapshot`을 SQLite에 같은 날짜 기준으로 교체 저장 | 계좌 조회, 원본 payload, 사용자 식별정보 |
| 시장 데이터를 로컬에 축적 | 가상 OHLCV를 종목별 Parquet에 날짜 기준 upsert | API endpoint, rate limit, 실제 종목·가격 |
| 데이터 시점과 형태를 검증 | 미래 시점·중복·정렬·OHLC 규칙을 검사 | 비공개 검증 게이트와 전략 평가 결과 |
| 저장된 상태를 API로 조회 | 로컬 미러 전용 FastAPI 5개 endpoint | 실제 제공자 호출과 쓰기 API |
| 운영 상태를 화면에서 확인 | 합성 요약·이력·보유·파이프라인 상태를 React로 표시 | 실제 장애·알림·승인·주문 흐름 |
| 전략 모듈의 교체 가능성 | `Strategy` Protocol만 공개 | 구체적인 전략 구현과 파라미터 |

이 표는 책임과 경계의 대응을 설명할 뿐, 두 저장소의 코드가 동일하다는 뜻이 아니다.

## 저장소에 들어오지 않아야 하는 파일

다음 파일과 디렉터리는 Git으로 추적하지 않는다.

- `.env`, `.env.*`
- `data/` 아래에서 생성한 SQLite·Parquet·JSON
- Python 가상환경과 캐시
- `node_modules`, 프런트엔드 빌드 결과와 coverage
- 로컬 IDE 설정과 로그

공개 전에는 아래를 확인한다.

```powershell
git status --short
git ls-files data .env ".env.*"
git grep -n -I -E "(client[_-]?secret|access[_-]?token|account[_-]?(no|number))"
```

마지막 검색은 코드의 일반적인 필드명도 찾을 수 있으므로 결과를 사람이 확인해야 한다. 단순히 검색 결과가 있다는 이유만으로 비밀 값이 포함됐다고 판단하지 않는다.

## 표현 원칙

- `실계좌 연동`, `운영 중`, `실시간`, `자동매매`를 이 공개 저장소의 기능처럼 표현하지 않는다.
- 합성 결과를 수익률이나 성능 성과로 소개하지 않는다.
- 비공개 저장소에서 통과한 테스트 수를 공개 저장소의 테스트 수처럼 사용하지 않는다.
- 구현 예정인 기능은 현재 기능 목록에 포함하지 않는다.
- 공개 저장소에서 직접 확인할 수 없는 사실은 README의 검증 결과로 적지 않는다.

## 보안과 면책

현재 API는 인증 없이 로컬 호스트에서만 실행된다. 공개 서버 배포를 전제로 한 보안 구현이 아니다.

이 저장소는 개발 구조를 설명하기 위한 예제이며 투자 자문, 종목 추천, 실제 주문 또는 투자 성과의 증빙을 제공하지 않는다.
